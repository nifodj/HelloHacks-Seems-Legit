# HelloHacks-Seems-Legit
HelloHacks 2026 Project
Purpose: Read an email or text conversation, and evaluate if it is a legitimate email. If it is a scam, provide next steps to prevent further scams, or details on account recovery if the scam has been clicked on.
Method: Receive an input, use a backend database to search for common scam email tendencies, then end with LLM to provide summary and next steps
